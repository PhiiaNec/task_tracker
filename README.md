# Выбор и подготовка к развёртыванию Kanban-трекера

## О проекте

Проект необходим для выбора системы управления задачами для небольшой команды (5–10 человек) в условиях закрытого контура без доступа к интернету.

**Цель работы:** определить подходящий self-hosted Kanban-трекер с учётом требований к функциональности, безопасности, интеграции с существующей системой поддержки и дальнейшему сопровождению.

## Что было сделано

- Сформулированы вопросы для уточнения требований заказчика и определены возможные варианты решений.
- Изучены особенности развёртывания Linux-серверов в условиях отсутствия интернета.
- Рассмотрены существующие self-hosted трекеры и отобраны три кандидата для подробного сравнения.
- Составлена сравнительная таблица **Redmine**, **Vikunja** и **Kanboard** по функциональным и техническим критериям.
- Обоснован предварительный выбор Kanboard с учётом требований к Kanban-доске, разграничению прав и простоте эксплуатации.

## Результат

В качестве предпочтительного решения выбран **Kanboard**.

О**сновные аргументы**:

- Kanban-доска является основным представлением системы и не требует установки дополнительных плагинов.
- Поддерживаются пользовательские роли и настройка прав доступа.
- Предусмотрен API для взаимодействия с внешними системами.
- Система ориентирована непосредственно на Kanban и не требует избыточных компонентов для реализации основного рабочего процесса.

Выбор является предварительным. Для окончательного решения необходимо было бы уточнить особенности существующей системы поддержки, требования к интеграции и возможности дальнейшего администрирования трекера.
